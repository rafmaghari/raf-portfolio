# Core tool marks

Nine inline SVG marks in `CoreToolIcon.tsx` are vendored from [Simple Icons](https://github.com/simple-icons/simple-icons/tree/17cd4ee07612198a1d8777a060d4100423762a8b/icons) at commit `17cd4ee07612198a1d8777a060d4100423762a8b`. No runtime dependency or remote image request is used. SVG wrappers are adapted for `currentColor`; paths are unchanged.

Simple Icons is [CC0-1.0](https://creativecommons.org/publicdomain/zero/1.0/), but underlying brand rights remain with their owners. Brand marks identify tools used; they do not imply endorsement.
